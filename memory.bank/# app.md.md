# 日记App设计文档

## 一、产品概述
本App是一款安卓端日记应用，核心使用方式为语音记录当天流水账式日记。  
用户口述完成后，App将自动：

1. 将语音转为文字；
2. 对内容进行分类（固定类别 + 动态标签）；
3. 整理成文章（保持口语风格，添加标点与分段）。

最终生成的日记可按日期存储、浏览、搜索，并支持日历功能和云端同步。

---

## 二、目标平台
- Android 6.0 及以上版本
- 上架国内应用商店，面向普通用户

---

## 三、核心功能需求

### 3.1 语音记录
- 主界面提供大麦克风按钮；
- 按下按钮开始录音，再次点击或松开结束录音；
- 支持不限时长的口述流水账；
- 显示录音实时反馈（音量波形、计时）；
- 保存录音文件，用于后续语音转文字。

### 3.2 语音转文字与AI处理
- 录音上传至云端处理：
  - 语音识别为文字；
  - 自动分类：
    - **固定类别**：从 {读书, 美食, 心情, 工作, 运动} 中匹配至少一个；
    - **动态标签**：AI自动生成短语标签（如 `#和同事聚餐`、`#读完三体`）；
  - 生成文章：保持口语语气，增加标点、合理分段，修正明显错别字，不改变叙事顺序，不改成第三人称。
- 处理完成后返回：
  - 原始语音文本
  - 分类结果
  - 动态标签
  - 生成文章

### 3.3 日记存储
- 每条日记包含：
  - 日期（录音当天）
  - 原始语音文件（可播放）
  - 语音识别文本
  - 生成文章
  - 预定义类别
  - 动态标签
- 支持同一天多篇日记存储

### 3.4 账户与云同步
- 用户注册/登录：
  - 手机号 + 验证码 或 邮箱 + 密码
- 日记数据云端自动备份
- 支持手动刷新同步
- 支持跨设备恢复日记

### 3.5 日记浏览（主页）
- 日记列表按日期倒序排列
- 日记卡片包含：
  - 日期（如“5月1日 周四”）
  - 固定类别标签（彩色圆点或文字）
  - 动态标签（灰色背景，可点击）
  - 文章前两行预览
  - 编辑和删除图标

### 3.6 日历功能
- 按月展示日历
- 有日记的日期标记彩色圆点
- 点击日期跳转至当天日记列表
  - 多篇日记：列表展示
  - 单篇日记：直接显示详情

### 3.7 查找功能
- 主界面顶部搜索框
- 支持：
  - 关键词搜索（文章内容、原文、动态标签）
  - 日期范围筛选
  - 固定类别筛选
- 搜索结果：
  - 按日期倒序
  - 高亮关键词
  - 显示摘要

---

## 四、非功能需求
- **处理等待提示**：录音完成后显示“AI正在整理你的流水账…”，处理完成自动跳转到日记详情页
- **离线录音支持**：无网络时可暂存录音，网络恢复后自动上传处理
- **隐私与合规**
  - 语音数据仅用于生成日记
  - 用户可删除云端数据
  - 符合国内应用商店上架要求（用户协议、隐私政策等）

---

## 五、技术与架构建议
- **前端**：Android 原生开发或 Kotlin + Jetpack Compose
- **后端**：云端语音识别、AI分类和文章生成服务
- **数据库**：
  - 本地：SQLite/Room
  - 云端：云存储 + 云数据库（如对象存储 + NoSQL）
- **同步机制**：支持增量同步、冲突处理

---

## 六、界面示意（文字描述）
- **主页**：日记列表 + 搜索框 + 新增录音按钮
- **录音页**：大麦克风按钮、音量波形、计时器
- **日记详情页**：文章显示、语音播放、标签展示、编辑/删除按钮
- **日历页**：月视图 + 日记标记
- **搜索结果页**：关键词高亮 + 摘要 + 日期排序
